# Proposal data sources

The preliminary proposal uses four public datasets from the Macao SAR Government Open Data Portal.

| Variable | Local file | Source |
|---|---|---|
| Visitor arrivals | `visitor-arrivals.csv` | https://data.gov.mo/Detail?id=3546225a-2a34-4645-b01e-6752aed03993 |
| Per-capita visitor spending | `per-capita-visitor-spending.csv` | https://data.gov.mo/Detail?id=f02b334a-cc44-4433-b942-672de0fdad13 |
| Total visitor spending | `total-visitor-spending.csv` | https://data.gov.mo/Detail?id=6466a42d-cd30-40a3-9017-3e0066e6b077 |
| Hotel occupancy rate | `hotel-occupancy-rate.csv` | https://data.gov.mo/Detail?id=8812ecc5-e9ab-4e2f-b971-d3c16e46bd32 |

These files support the planning stage of the pair project. They are retained to make the proposal verifiable and reproducible.
