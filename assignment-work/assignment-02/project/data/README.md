# Data sources

| File | Source | Purpose |
|---|---|---|
| `manual_ces.csv` | BLS Current Employment Statistics | National and industry employment series |
| `manual_sae.csv` | BLS State and Area Employment | State-level employment series |
| `fred_payems.csv` | FRED series `PAYEMS` | Independent national-total check |
| `us-states.json` | Public U.S. state boundaries | Choropleth map geometry |

Primary sources:

- https://www.bls.gov/ces/data/home.htm
- https://www.bls.gov/sae/data/home.htm
- https://fred.stlouisfed.org/series/PAYEMS

The analysis period is January 2019 to April 2023. The files are included to make the completed analysis reproducible.
