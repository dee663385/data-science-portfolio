# Lab 01 - Automobile sales visualisation

The final notebook completes twelve visual-analysis tasks using pandas, Matplotlib, Seaborn, and Folium.

## Figure index

| Figure | Task |
|---|---|
| `01-average-sales-by-year.png` | Average automobile sales by year |
| `02-annotated-sales-trend.png` | Annotated yearly sales trend |
| `03-sales-vs-advertising.png` | Sales and advertising expenditure in non-recession periods |
| `04-recession-only-bar.png` | Average sales during recession periods |
| `05-vehicle-type-comparison.png` | Vehicle-type sales during recessions |
| `06-gdp-subplots.png` | GDP comparison with subplots |
| `07-seasonality-bubble.png` | Seasonality bubble plot |
| `08-consumer-confidence.png` | Consumer confidence and sales |
| `09-price-vs-sales.png` | Price and sales during recessions |
| `10-advertising-share.png` | Advertising share by period |
| `11-vehicle-advertising-pie.png` | Recession advertising share by vehicle type |
| `12-unemployment-vs-sales.png` | Unemployment rate, vehicle type, and sales |

## Run the notebook

Install the repository dependencies, then open or run `automobile-sales-visualisation.ipynb` from a clean kernel. Some tasks retrieve the course-hosted automobile-sales dataset over the internet.
